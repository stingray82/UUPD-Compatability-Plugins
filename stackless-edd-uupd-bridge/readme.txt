Connects Stackless EDD Software Licensing to UUPD updater clients and deploy.sh release publishing. Adds per-download bootloader generation, update artwork controls, metadata sections and order licence key copying.

== Description ==
Provides UUPD REST compatibility for Stackless EDD licence activation and update metadata; a deploy.sh-compatible authenticated release endpoint; native EDD product configuration and bootloader/inline code generation; WordPress Media Library and HTTPS URL artwork pickers; and copyable licence keys on order details.

Install on the EDD store with Stackless EDD Software Licensing enabled. See README.md for full setup details and storage security requirements.
